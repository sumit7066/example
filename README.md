# 🍽️ Zomato Dashboard 2026 – Power BI Project

## 📌 Project Overview

The **Zomato Dashboard 2026** is a data visualization project developed using Microsoft Power BI. It focuses on visualizing Zomato restaurant data and exploring geographical information through interactive dashboard elements.

The project uses Power BI to transform restaurant-related data into meaningful visual insights, helping users explore restaurant locations and understand geographical distribution.

## 🎯 Project Objectives

- Analyze Zomato restaurant data.
- Visualize restaurant locations across different localities.
- Explore geographical distribution using map visualization.
- Present data through an interactive Power BI dashboard.
- Practice data analytics and business intelligence concepts.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Data visualization and dashboard development.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Data analysis and calculations (where applicable).
- **Data Visualization** – Geographical map visualization.

## 📊 Dashboard Features

- **Dashboard Title:** ZOMATO Dashboard 2026
- **Geographical Visualization:** Filled Map.
- **Location Analysis:** Locality-based visualization.
- **Dataset:** ZomatoData.
- **Dashboard Layout:** Single-page dashboard.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `zomato dashboard.pbix` file.
4. Wait for the report and dataset to load.
5. Explore the dashboard and its visualizations.
